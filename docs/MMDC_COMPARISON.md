# mmdc vs Rust mermaid-cli 详细对比

**目标**：理解两个 mermaid-cli 实现之间的核心差异和各自优势。

---

## 📋 项目背景

### mmdc（官方 Node.js 版本）
- **地址**：https://github.com/mermaid-js/mermaid-cli
- **包名**：@mermaid-js/mermaid-cli
- **语言**：JavaScript (Node.js)
- **核心技术**：Puppeteer + Chromium 浏览器渲染
- **发布时间**：2018 年
- **维护状态**：活跃但缓慢（~90 开放 issue）

### Rust mermaid-cli（本项目）
- **地址**：本地项目
- **语言**：Rust
- **核心技术**：原生 SVG 生成 + 直接渲染
- **发布时间**：2026 年（新项目）
- **维护状态**：活跃（最新 v0.2.1-alpha）

## 🔧 技术架构对比

### mmdc 架构

```
.mmd/.md 文件
    ↓
Node.js 解析
    ↓
启动 Chromium 进程 (Puppeteer)  ← 性能瓶颈
    ↓
加载 mermaid.js 库
    ↓
在虚拟 DOM 中渲染
    ↓
导出 SVG/PNG/PDF
    ↓
输出文件

特点：
- ❌ 必须依赖浏览器渲染
- ❌ 每次渲染都要启动 Chromium
- ❌ SVG 质量依赖浏览器版本
```

### Rust 版本架构

```
.mmd 文件
    ↓
Rust Lexer & Parser
    ↓
AST（抽象语法树）
    ↓
Renderer（直接生成 SVG）  ← 高性能
    ↓
SVG Builder（手动构建）
    ↓
PNG 转换（resvg 库）
    ↓
输出文件

特点：
- ✅ 原生二进制编译
- ✅ 零浏览器依赖
- ✅ 完全可控的渲染引擎
```

## 📦 依赖项和安装

### mmdc 依赖

```bash
# 安装
npm install -g @mermaid-js/mermaid-cli

# 实际占用
node_modules/
├── puppeteer/           (~200MB)
├── chromium/            (~150-300MB)  ← 自动下载
├── mermaid/             (~5MB)
└── 其他依赖...          (~50MB)

总计：~300-500MB（首次安装很慢）

# 核心依赖
- Node.js 12+
- Chromium（自动下载）
- 系统依赖库（libnss3 等）
```

### Rust 版本依赖

```bash
# 编译
cargo build --release

# 实际占用
target/release/
└── mermaid-cli          (~50MB 单二进制)

总计：< 10MB（零运行时依赖）

# 核心依赖
- Rust 工具链（编译时）
- 标准库（编译进二进制）
- 无运行时依赖
```

### 安装对比

| 方面 | mmdc | Rust 版 |
|------|------|--------|
| **首次安装** | 5-10 分钟 | 2-3 分钟 |
| **网络问题** | 常见（Chromium 超时） | 不存在 |
| **兼容性** | 版本依赖复杂 | 编译一次到处运行 |

## 📋 CLI 命令对比

### mmdc 命令

```bash
# 基础渲染
mmdc -i diagram.mmd -o output.svg

# 指定格式
mmdc -i diagram.mmd -o output.png -e png

# 自定义尺寸
mmdc -i diagram.mmd -o output.png -w 1920 -H 1080 -s 2

# 主题
mmdc -i diagram.mmd -t dark -o output.svg

# 批量处理
mmdc -i '*.mmd' -o output/

# 配置文件
mmdc -i diagram.mmd -c config.json -o output.svg

# 自定义 CSS
mmdc -i diagram.mmd -C custom.css -o output.svg
```

### Rust 版本命令

```bash
# 基础渲染
mermaid-cli diagram.mmd -o output.svg

# 指定格式
mermaid-cli diagram.mmd -o output.png -e png

# 自定义尺寸
mermaid-cli diagram.mmd -o output.png -w 1920 -H 1080 -s 2

# 语法检查
mermaid-cli diagram.mmd check

# 自动修复
mermaid-cli diagram.mmd fix

# AST 输出
mermaid-cli diagram.mmd -e json

# 帮助
mermaid-cli --help
```

## 🎯 项目定位总结

### mmdc（官方版本）
- 📍 **定位**：通用、功能完整的图表渲染工具
- 🎯 **适合**：开发者工具、文档生成、一次性渲染
- ⚠️ **限制**：性能不足以应对大规模/实时场景

### Rust mermaid-cli（本项目）
- 📍 **定位**：高性能、AI 友好的图表渲染引擎
- 🎯 **适合**：AI 系统、大规模渲染、容器部署
- ✅ **优势**：性能、依赖、智能纠错
