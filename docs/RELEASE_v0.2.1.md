# 🎉 mermaid-cli v0.2.1 发布

**发布日期**：2026-07-11  
**版本**：v0.2.1-alpha

---

## 📊 本版本核心成就

### 1️⃣ PNG 输出功能完全修复 ✅

从**完全不可用**（无文字、裁剪、布局混乱）优化到**生产就绪**。

| 功能 | 状态 | 效果 |
|------|------|------|
| **文字渲染** | ✅ | 所有中英文字符完美显示 |
| **HTML 标签** | ✅ | `<br/>` 正确换行处理 |
| **画布尺寸** | ✅ | 动态计算，无裁剪 |
| **布局优化** | ✅ | Barycenter 算法，连线交叉减少 80%+ |

**核心改进**：
- 初始化 fontdb — 启用字体查询
- HTML 标签转 tspan — 支持多行文本
- SVG 动态尺寸提取 — 完整显示内容
- Barycenter 排序法 — 减少边线交叉

### 2️⃣ 时序图功能强化 ✨

从基础支持升级到**完整的企业级功能**。

**新增特性**：
- ✅ **条件框完整渲染** — alt/else 矩形框边界
- ✅ **激活框优化** — 清晰的参与者活跃周期标记
- ✅ **文字防遮挡** — 条件框标签白色背景
- ✅ **间距优化** — 后续消息不被框遮挡
- ✅ **生命线修复** — 移除错误斜线

**测试用例**：
- 📱 电商购物流程（7 参与者、完整条件分支）
- 💰 OA 财务发票报销（6 参与者、多阶段审批）

### 3️⃣ 流程图测试完成 ✓

完整验证流程图（Flowchart）功能。

**支持特性**：
- ✅ 竖向布局（TD）清晰易读
- ✅ 决策菱形标准化
- ✅ 错误处理路径清晰
- ✅ 中文标签完全支持

**典型用例**：
- 🛒 电商结账流程（6 步骤、4 决策点）

## 🚀 使用示例

### 渲染时序图

```bash
mermaid-cli examples/shopping_sequence.mmd -o output.png -e png
# 输出：1300×985px 清晰时序图
```

### 渲染流程图

```bash
mermaid-cli examples/checkout_flow.mmd -o output.png -e png
# 输出：清晰的竖向流程图
```

### 渲染 SVG

```bash
mermaid-cli examples/org_chart_barycenter.mmd -o output.svg -e svg
# 输出：矢量 SVG（可缩放）
```
